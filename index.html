Machine Learning Prediction of Antimicrobial Resistance in E. coli

STACK: Python, Google Colab • SUPERVISOR: Dr. Preeti Solanki • Code on GitHub ↗
  • Built an end-to-end Python pipeline to predict resistance to ciprofloxacin, ampicillin, and gentamicin from gene presence/absence data (1,936 isolates, 17,198 accessory genes; Moradigaravand et al., 2018).
  • Selected features per antibiotic using chi-square and odds ratio (p < 0.05, OR > 2); trained logistic regression, random forest, and gradient boosting (stratified 70/30 split, 5-fold cross-validation); achieved test AUC 0.94–0.96.
  • Checked model interpretation against known resistance mechanisms (aac3-VI, bla, Tn21/class 1 integron elements). Showed that ciprofloxacin predictions were driven by plasmid-maintenance genes rather than gyrA/parC, indicating that a high AUC can reflect lineage structure.

Differentially Expressed MicroRNAs in Breast Cancer: Analysis of GSE45666

TOOLS: GEO2R, R • SUPERVISOR: Dr. Preeti Solanki
  • Analysed public microarray data (breast tumour vs adjacent normal tissue) using GEO2R and R, applying an FDR-adjusted p-value cutoff and a fold-change threshold.
  • Identified differentially expressed miRNAs, predominantly downregulated in tumours. Top downregulated: hsa-miR-139-5p, -99a, -125b.
  • Top upregulated: hsa-miR-182, -21*, -210. Produced volcano plots and UMAP clustering showing separation between tumour and normal samples.
  • Compared findings with the literature, including tumour-suppressor roles of miR-139-5p and miR-99a and the oncogenic role of miR-21.
